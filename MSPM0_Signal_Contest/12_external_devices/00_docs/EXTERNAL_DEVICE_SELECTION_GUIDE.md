# External Device Selection Guide

本页只帮助判断控制类别和基本方案边界。具体型号最终由题目指标、手头器件和模拟硬件决定。

## 外置 ADC

| 需求 | 先考虑 | 原因 |
|---|---|---|
| 低速小信号、传感器、高增益 | ADS112C04 类 ΔΣ ADC | 16-bit、PGA、低速滤波，但最高 2 kSPS |
| 中速 12-bit 波形 | ADS7866 类 SAR | 帧简单、约 200 kSPS |
| 更高速、10-bit 足够 | ADS7887 类 SAR | 可到 1.25 MSPS |
| 多通道同步/并行 | AD7606 family 类 | 数据线与控制线更多，先看 Parallel Recipe |

不要只比较 bit 数。先核对输入带宽、Fs、SNR/ENOB、参考、驱动建立时间和数据吞吐。

## DAC 与 DDS

| 需求 | 先考虑 |
|---|---|
| 任意样点/波形、低中速连续输出 | DAC + Timer/DMA |
| 直流或精密控制电压 | 电压输出 DAC；DAC7811 需 I/V 电路 |
| 精细设频的连续正弦/三角/方波 | AD9833 |
| 更宽 32-bit FTW、常见高速 DDS 模块 | AD9850 |

DDS 通常不能直接数字设置任意 amplitude/offset；要靠外部增益、衰减、偏置和滤波。

## 数字电位器与 PGA/VGA

| 情况 | 方式 |
|---|---|
| 需要可读写 0..127，I2C 简单 | TPL0401A-10 |
| 需要掉电保存，允许逐步移动 | X9C104S |
| 需要明确 1..200 倍增益档 | PGA113 |
| 增益由连续控制电压决定 | DAC/PWM + VGA，查 Analog Voltage Recipe |

先检查端点电压、wiper 电流、共模、带宽和输出饱和；数字控制正确不代表模拟链正确。

## 模拟开关

| 情况 | 方式 |
|---|---|
| 双路 4:1 或三组 2:1，普通低速 | CD4052/CD4053 |
| 4 路独立开/关 | CD4066B |
| 高压 8:1 | MAX14752；必须高压安全设计 |

3.3 V GPIO 是否能驱动取决于开关控制端供电和 VIH。模拟信号必须在开关电源轨内，并考虑 RON、带宽、漏电和切换毛刺。

## MCU 管脚不够

慢速开关/LED/按键可用 TCA6408A I2C GPIO 扩展；精确 PWM、ADC 触发或高速 bit-bang 仍应使用 MCU 本地外设。
