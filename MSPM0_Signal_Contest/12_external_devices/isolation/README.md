# 隔离器件：未来器件入口

README 类型：`FUTURE_CATEGORY_INDEX`

- 隔离后的 I2C：[I2C Register Device Recipe](../00_docs/recipes/I2C_REGISTER_DEVICE_RECIPE.md)
