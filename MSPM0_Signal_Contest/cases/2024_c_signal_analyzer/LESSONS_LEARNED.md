# 2024 C Lessons Learned

## L01: “有方波”不等于“发生猝发”

比较器输出对普通周期信号同样可能翻转，ADC1 只能说明门控通道在窗口内有活动，不能独自提供模拟波形的起止边界。

## L02: 采集和分析必须解耦

FFT、浮点格式化和 TFT SPI 写入会远慢于一次 DMA 块切换。把它们放进 ADC/DMA ISR 会造成采样空洞；ISR 应只确认完成、保存索引和切换下一个目标块。

## L03: 低频显示不能使用固定时间窗

固定窗在 100 Hz 左右只能看到一小段波形。周期显示应使用硬件捕获频率计算三个周期；复合频谱则使用 FFT 基波，两个时间基准不能混用。

## L04: 外部偏置必须动态估计

即使题目示例提到 1.5 V，也不能直接减常数。先恢复外部调理增益，再由当前有效窗口求均值去 DC，才能适应偏置变化。

## L05: 屏幕只刷新变化区域

整屏刷新会让示波器体验闪烁，也浪费主循环时间。静态布局只画一次，波形框和数字字段分别清除/重画，并给可变长度数字预留固定宽度。

## L06: 缺少的正式模块

本案例仍把 `signal_burst_detector`、`signal_dual_adc_ring_recorder`、`signal_waveform_classifier`、`signal_fundamental_estimator`、`signal_analyzer_screen` 和测量控制器写在应用层。它们是后续最值得整理成正式模块的知识缺口。
