# 2024 C Decision Trace

## D01: ADC1 是标志，不是边界

用户实测发现 PA17 上有比较器方波但猝发经常漏检或不完整。原因是普通周期输入也会让 ADC1 翻转，而且异步中断只能告诉软件某一时刻的电平。最终方案把 ADC1 纳入同步 DMA，只作存在性标志；猝发起止和幅度由同一时间基准下 ADC0 的动态活动区间确定。

## D02: DMA 中断集中管理

此前 ADC0/ADC1 分开的 ISR 会互相清状态，主循环处理 FFT/TFT 时还会错过下一块。最终由 `DMA_IRQHandler()` 统一等待两个通道完成，并在 ISR 内快速切到下一个三缓冲目标，耗时处理延后到主循环。

## D03: 频率来源按任务分开

硬件整形频率适合周期信号的时间轴，尤其是 95 Hz 到 100 Hz 低频显示；复合信号的 H1 和谐波必须按 FFT 频率分析，不能被硬件测频覆盖。该分支是解决 100 Hz 波形不满三周期和 H1 被显示为 0 的关键。

## D04: 去直流不假定 1.5 V

外部调理的偏置不是软件常数。ADC code 恢复电压后，调用 remove-DC 逻辑对当前有效窗口求均值并原地减去，因而换比较器阈值或偏置仍可工作。

## D05: 三角波归入 SAW

分类器以对称度、斜率和谐波特征区分正弦、锯齿/三角、脉冲和复合；按照题意三角波显示 `SAW`，不引入新的类型字符串。
