# 2024 C 信号检测与波形分析仪成功案例

本案例记录 `fuxian/24_C` 已完成并由用户确认成功运行的 MSPM0G3507 竞赛工程。它是可复用的架构先例，不是新的 API、Datasheet 或 SysConfig 真值；新题目必须重新检查当前模块卡、目标 `.syscfg`、生成头文件、Pin、采样率和 RAM。

## 解决的问题

工程测量经过外部调理的正弦、锯齿、脉冲、复合和单次猝发信号。模拟通道经过约 0.6 倍缩小并叠加未知直流偏置，因此软件先按增益恢复交流幅度，再对当前有效窗口动态去均值，不把偏置固定写成 1.5 V。数字整形信号进入 TIMG6 做硬件测频和占空比，TFT 同页显示参数和波形。

## 最关键的成功架构

ADC0 连接 PA25，负责唯一的模拟波形数据；ADC1 连接 PA17，采集外部比较器输出，仅作为猝发存在标志。两路 ADC 由同一个 TIMG0 ZERO Event 同步触发，DMA_CH0/CH1 同步搬运。DMA 中断只做两路完成确认和下一块目标地址切换，FFT、分类、统计、TFT 绘制全部留在主循环，避免处理时间造成采样空洞。

猝发武装后使用三块连续双通道 DMA 缓冲。ADC1 不能直接决定波形边界，因为普通周期信号也会产生比较器方波；边界由 ADC0 的动态活动区间和前后 margin 决定，ADC1 只确认事件确实出现。命中后停止后续 DMA，拼接并锁存完整事件窗口，屏幕显示一次完整猝发波形、持续时间和最大幅度。

## 周期信号和复合信号

周期信号的频率优先使用 PB2/TIMG6 的硬件捕获得到的频率，并按 `round(3*Fs/frequency)` 截取三个周期，因此 95 Hz 附近也能完整显示三周期。复合信号的 H1 和 H1~H5 分析只使用 FFT 结果，横轴按 FFT 基波频率设置，避免硬件整形频率覆盖频谱分析结果。

FFT 使用 CMSIS-DSP Q15，窗口为 Hann。先去当前窗口均值，再做 Hann 和 Q15 FFT，基波采用峰值附近三点插值，谐波使用目标频率附近的多 bin 能量并做窗口幅度恢复。三角波按比赛约定归类为 `SAW`，没有增加 `TRIANGLE` 类型。

## 显示策略

上电时只执行一次整屏清空并绘制静态布局、X-Y 坐标轴、网格和单位。运行时仅清除并重画波形区域以及发生变化的数字字段，避免整屏闪烁。纵轴显示 V 单位和刻度，横轴显示 ms；猝发锁存后保持页面，不被后续无关 DMA 帧覆盖。

Search anchors: composite signal, FFT fundamental, H1~H5 harmonics, three periods, local TFT dirty refresh, full burst waveform.

## 复用边界

可复用的是同步采样、DMA 所有权、事件锁存、频率来源选择和显示刷新策略。不要直接复制整个工程或继承验证状态。比较器极性、电平、阈值、ADC 采样率、TIMG 分频、DMA 缓冲数量、显示 Pin 和生成宏都必须在新工程中重新核对。
