Zoom FFT 通常通过数字下变频、窄带低通、抽取，再对较低采样率数据 FFT 来放大某个频带。它要求混频器、抗混叠滤波器、抽取和频率映射全部正确，不是简单把 Fs 数字改小。

Benefits：把算力集中到已知窄频带。Trade-offs：链路长、滤波器瞬态/延迟/幅相校正复杂，可能漏掉带外目标。

When NOT to use：目标频段未知、单次宽带瞬态、没有滤波器响应验证或比赛现场才第一次调参数时。
