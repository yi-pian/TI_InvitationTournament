# Contest Signal Task Archetypes：信号/测量赛题原型

这不是历年题目的替代品，也不替你选方案。它把公开赛题和当前仓库复现中反复出现的“任务形状”归类，方便去 `MODULE_SELECTION_GUIDE.md` 找对应 Pipeline。

## 1. 证据与使用边界

本次只把下面资料当题型证据：

- 东南大学电工电子国家级实验教学示范中心的[历年竞赛题目录](https://eae.seu.edu.cn/48000/list9.htm)：可见 X-Y 波形产生、频率补偿、网络阻抗等历史题型。
- 东南大学公布的[1995—2011 年获奖题目表](https://eae.seu.edu.cn/2012/0925/c47972a451871/page.htm)：包含实用信号源、简易数字频率计、频率特性测试仪、波形发生器、数字式相位测量等名称。
- TI 官方[2022 年 TI 杯参考赛题 PDF](https://www.ti.com.cn/cn/lit/ug/zhcn005/zhcn005.pdf)：包含信号调制度测量/识别/显示与混沌信号 X-Y 相图等完整任务。
- TI 官方[2021 A 题信号失真度测量装置解析](https://www.ti.com.cn/zh-cn/video/6311733346112)：确认失真度测量是实际赛题类型。
- 东南大学对模拟邀请赛的官方总结说明命题覆盖“模拟信号获取、处理、转换、产生”和“测量与控制”；见[2020 年竞赛总结](https://eae.seu.edu.cn/2023/0828/c49564a461960/page.htm)。
- 本仓库本地复现：`fuxian/2024_C_signal_detection_display/`、`fuxian/dac_harmonic_display/`、`08_applications/`。本地项目只证明仓库曾集成相应链，不代表官方赛题原文。

下面的“典型输出”是对公开任务的工程归纳；频率、幅值、误差和必须器件仍以拿到的题目原文为准。

## 3. 从题目原型到软件层次

```text
题目要求
  ↓
Application：把采集、算法、显示、交互和验证组织成完整作品
  ↓
Recipe：描述从输入到结果的完整逻辑链；可组合多个 Primitive
  ↓
Primitive / Hardware Module / DriverLib：真正执行一次可复用运算或硬件动作
```

不要因为某原型出现在本表，就认为仓库已有完整 Application。实际状态必须看 `MODULE_SELECTION_GUIDE.md` 的节点类型和 `CONTEST_PIPELINE_GAP_AUDIT.md`。

## 4. 历史题型带来的四条共同结论

1. **显示是交付的一部分。** TI 2022 调制度测量题明确要求测量、识别和显示；只在调试器里得到 float 不等于完成系统。
2. **模拟前端是测量链的一部分。** 高频、微弱、双极性、高压或高动态范围输入不能靠软件忽略电气边界。
3. **自动化经常是评分点。** 一键测量、扫频、识别、显示意味着状态推进和资源协作，而不是单次函数调用。
4. **同一输出可有不同后端。** frequency 可以来自 Timer Capture、ADC crossing、FFT 或 Autocorrelation；应按波形、噪声、带宽和资源选择。
