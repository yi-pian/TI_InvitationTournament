# Offline Assembly Checklist

这是 [OFFLINE_MODULE_ASSEMBLY_WORKFLOW.md](OFFLINE_MODULE_ASSEMBLY_WORKFLOW.md) 的可选现场勾选版，仅用于 B 复杂硬件模块和 C 算法模块，不是总流程。开始前先在 [CONTEST_IMPLEMENTATION_GUIDE.md](CONTEST_IMPLEMENTATION_GUIDE.md) 完成实现层级判断。

- [ ] STEP 0：该功能确实属于 B Complex Hardware Module 或 C Algorithm Module。
- [ ] STEP 1：需要的正式模块已经选好。
- [ ] STEP 2：已按需阅读每个模块 README。
- [ ] STEP 3：模块已逐个加入，并在每次加入后 Build PASS。
- [ ] STEP 4：已统一检查题目参数，完成 Clean、Build 和上板验证。

遇到接口、参数或 SysConfig 问题时再查看对应工具书，不需要提前全部阅读。
