# 相位方法选择

统一输出都是 `phase_B - phase_A`；正值表示 B 相位领先 A，负值表示 B 滞后 A。

| 场景 | ZeroCross Phase | FFT Phase | CrossCorrelation Phase |
|---|---|---|---|
| 纯正弦、SNR高 | 推荐，最省 RAM | 推荐，已有 FFT 时方便 | 可用但计算浪费 |
| 有噪声 | 易抖/假过零 | 推荐，聚焦目标频率 | 推荐，整段平均相似度 |
| 有谐波 | 过零点会被移动 | 推荐，可只取基波 | 波形相似时可用 |
| 低频、周期内点数多 | 很好 | N/记录要覆盖足够周期 | L 可能很大、计算重 |
| 高频、每周期点数少 | 插值仍受点数限制 | 通常更稳 | lag 量化粗，需要亚样本插值 |
| 非正弦但两路形状相似 | 可能多次过零 | 只代表选定频率相位 | 推荐 |

三种方法共同前提：双通道时间对应关系已知。若 B 通道固定晚 `delay_s`，它产生 `-360*f*delay_s` 度的假相位，频率越高越严重；应先做 ChannelDelayCalibration。

推荐顺序：纯正弦先 ZeroCross/FFT 互相校验；复杂波形用 Correlation；结果差异大时先查同步采样、DC、窗、阈值和周期配对，不要平均三个互相矛盾的方法。
