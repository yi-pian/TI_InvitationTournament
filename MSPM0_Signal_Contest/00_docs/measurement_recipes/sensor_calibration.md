# Sensor Calibration：传感器标定与工程单位换算

## 输入与输出

- 输入：已完成 ADC 电气校准的电压/码值、参考物理量 `true_unit[k]`、环境条件和传感器激励参数。
- 输出：工程单位值、校准模型参数/LUT、残差、不确定度和有效范围。

## 逻辑链

```text
ADC raw → ADC电压校准
→ 传感器零点/激励/温度稳定
→ 多个已知参考点，每点多帧稳健统计
→ 选择最简单能满足残差的模型：
   两点 affine → 多点线性最小二乘 → 分段LUT → 必要时低阶多项式
→ 用未参与拟合的验证点检查最大误差
→ 保存模型、单位、范围、温度、方向和版本
→ 正式测量：输入校验 → 模型换算 → 表内插值 → 质量/表外状态
```

ADC 校准与传感器校准分层：前者把 code 变成真实电压，后者把真实电压变成温度/压力/位移等物理量。混成一个不可解释公式会让换 ADC 或前端后无法复用。

## 为什么采用最低复杂度模型

先用 affine 可以直接看出灵敏度和零点；只有独立验证点证明残差存在可重复非线性时才升级 LUT。这样能避免用高阶多项式拟合噪声，也让 MCU 计算、表外行为和故障排查保持可解释。

## 推荐、备选与失效

| 特性 | 默认模型 | 升级条件 | 失效条件 |
|---|---|---|---|
| 近似线性 | 两点/多点线性 | 残差有稳定曲率 | 参考点太少却用高阶拟合 |
| 单调非线性 | 分段 LUT+插值 | 表很大才考虑近似公式 | 非单调/迟滞 |
| 温度影响明显 | 多温区 LUT 或温度系数 | 有足够标定数据 | 用室温表覆盖全温区 |
| 迟滞 | 上升/下降分别标定 | 需要状态模型 | 单一无状态映射 |

## 采样、抗噪声与精度

- 每个参考点等待传感器和模拟前端稳定；记录重复性、回程误差和温度。
- 用 Median/MAD 识别采集异常，再用 Mean/Statistics 估计中心和标准差。
- 标定点应覆盖比赛实际范围，关键工作区加密；禁止表外静默外推。
- LUT + 线性插值通常比 MCU 上复杂公式更安全，但表本身需要版本、CRC/默认值策略由 Application/BSP 负责。

## MCU / RAM 与 Primitive

- affine O(1)；LUT 查找 O(log K)、RAM 约每点 8 字节（输入/输出 float）。
- 复用 ADC Calibration、Statistics、MAD。
- 通用 `calibration_lut_1d` 是 ADC/DAC/VGA/频响/传感器共同 P0 缺口；不要为每种传感器复制一套插值实现。
