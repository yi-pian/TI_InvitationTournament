# Contest Problem Analysis Template

复制本模板到 `contest_reproductions/YYYY_problem_name/PROBLEM_ANALYSIS.md`。每一项都必须写题面原文、工程解释和假设；未知项标 `TBD`，不得自行伪造。

1. **题目输入是什么**：端口、源阻抗、连接方式、是否共地。
2. **输出是什么**：数值、波形、控制信号、显示/通信格式。
3. **信号类型**：正弦/方波/脉冲/调制/任意周期/非周期。
4. **频率范围**：最小、最大、瞬时变化速度。
5. **幅值范围**：峰值、峰峰值或 RMS；必须注明定义。
6. **DC 范围**：允许偏置与极性。
7. **干扰**：工频、谐波、邻频、共模、毛刺。
8. **噪声**：SNR 或噪声带宽；未知则列验证方法。
9. **精度要求**：绝对误差/相对误差/分辨率。
10. **响应时间**：首次结果、刷新率、稳态时间。
11. **通道**：单/双通道；是否需要同步。
12. **连续信号**：是/否；若是，是否允许块处理空窗。
13. **突发信号**：是/否；触发、前后触发长度。
14. **是否产生信号**：波形、频率、幅值、负载。
15. **是否测相位**：参考通道、符号、wrap 范围。
16. **是否测谐波**：阶数、幅值定义、带宽。
17. **是否测 THD**：THD/THD+N，最大阶数和计算定义。
18. **模拟前端**：衰减/增益、偏置、保护、抗混叠、输入阻抗。
19. **ADC 方案**：通道、分辨率、VREF、触发源、DMA。
20. **Fs**：计算式、定时器可实现值、允许误差。
21. **N**：分辨率/延迟/周期覆盖计算。
22. **外设模块**：从 Integration Module Index 逐项选择。
23. **算法模块**：只写正式算法库真实 API。
24. **Recipe**：主 Recipe + 备用 Recipe；写明切换条件。
25. **RAM 预算**：逐 Buffer 列 `类型字节数 × 元素数`，再留 stack/通信余量。
26. **CPU 预算**：每帧周期、最坏算法链、是否需要 target cycle benchmark。
27. **误差预算**：时钟、VREF、前端、量化、窗、算法、同步。
28. **校准需求**：VREF、ADC gain/offset、通道 delay、DUT reference。
29. **显示/输出**：UART/UI/CSV，刷新率和小数位。
30. **验证方案**：PC truth、信号源/示波器/频谱仪、扫描点、通过阈值。
