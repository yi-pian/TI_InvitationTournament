# Fixed-point policy

适用目标：MSPM0G3507，Cortex-M0+，80 MHz，32 KB SRAM，无硬件 FPU。

## 默认数据链

| 阶段 | 默认类型 | 说明 |
|---|---|---|
| ADC DMA 缓冲 | `uint16_t` | 保留 ADC 原始码，不在采集模块里隐式去直流或缩放 |
| 时域 DSP 输入 | Q15 (`int16_t`) 或现有 float | 新的高吞吐定点路径优先 Q15；现有公开 API 暂不改签名 |
| 比赛 FFT | CMSIS-DSP Q15，复数交错 | `real0, imag0, real1, imag1...`；当前默认候选已通过构建和 PC 数值测试 |
| 功率/平方和 | Q31、`int64_t` 或 `double` 参考 | 累加前必须写明最坏范围和是否饱和，禁止直接在 Q15 中累加平方 |
| 最终测量值 | `float` | 频率、幅值、相位等对外结果便于标定和显示 |
| 标量定点数学 | IQ24 (`int32_t`) | 只用于明确选择 IQMath 的乘除、sqrt、sin/cos、atan2 等标量运算 |
| PC reference | `float`/`double` | 作为真值近似和回归基线，不等同目标端最快实现 |

## 格式定义

- Q15：有符号 1.15，实数值为 `raw / 32768`，范围 `[-1, 1)`。
- Q31：有符号 1.31，实数值为 `raw / 2147483648`，范围 `[-1, 1)`。
- IQ24：有符号 8.24，实数值为 `raw / 16777216`。它用于标量数学，
  不是 FFT 数据格式。
- 所有结构体字段、函数参数和缓冲区名称必须注明格式；不能只写 `int32_t data`。

## ADC 到 Q15

统一使用 `SignalFixedPoint_AdcU16ToQ15()`。对 12 位 ADC：

| ADC raw | Q15 raw | 归一化值 |
|---:|---:|---:|
| 0 | -32768 | -1.0 |
| 2048 | 0 | 0.0 |
| 4095 | 32752 | 0.99951171875 |

这是以半量程为零点的线性映射，不会自动估计信号真实直流偏置。若需测量后去直流，
仍由 `RemoveDC` 或相应 recipe 负责。

## 集中转换 API

- `SignalFixedPoint_AdcU16ToQ15()`
- `SignalFixedPoint_Q15ToF32()`
- `SignalFixedPoint_Q15ToIQ()`
- `SignalFixedPoint_IQToF32()`

实现位于 `algorithm_backends/signal_fixed_point.*`。应用层不得重复实现。

## 缩放和溢出规则

1. 每个定点算法必须在接口文档中注明输入 Q 格式、输出 Q 格式和内部缩放。
2. CMSIS Q15/Q31 CFFT 的前向结果带逐级缩放；本仓库 PC 对照按 `FFT/N`
   验证。调用方在计算幅值时必须恢复所需的 `N`、窗增益和单边谱系数。
3. `arm_cmplx_mag_q15` 的输出为 2.14 格式，不能按普通 Q15 解读。
4. `arm_atan2_q15` 输出为 Q2.13 弧度；`arm_sin_q15/arm_cos_q15` 的输入是
   一圈归一化相位，不是 Q15 弧度。
5. 乘法先扩展后乘；累计使用至少 64 位或有证明的饱和 Q31 路径。
6. 浮点转定点必须规定舍入和饱和。禁止依赖越界强制转换、整数溢出或未定义行为。
7. 格式边界只在模块入口/出口转换；禁止在循环内反复 Q15↔float↔IQ。

## 4096 点内存约束

单个复数 Q15 FFT 缓冲为 `4N = 16384 B`。ADC 4096 点原始缓冲为 8192 B，
若再保留 4096 点 Q15 幅值缓冲又需 8192 B，三者已经用满 32 KB，尚未计栈和状态。
因此 4096 点正式 recipe 必须复用内存、就地转换、分段计算幅值或只保留目标频点；
“单 FFT 能链接”不等于“完整应用能同时保留所有缓冲”。
