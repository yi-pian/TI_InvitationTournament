# Contest Reproductions

此目录仅保留为手工练习区，不是 Integration Library 主入口。

你完成题目分析并自行选好模块后，可以手工建立例如 `2024_C/`：

1. 复制 `08_applications/signal_contest_template/` 的必要工程文件。
2. 用 `00_docs/MODULE_INDEX.md` 找正式模块。
3. 用 Interface Matrix 与 Assembly Guide 手工连接。
4. 修改 config，必要时修改 SysConfig。
5. full build/link，检查 `.map`，再做 PC/Board 验证。

原来的完整题目分析/Requirement/Recipe 自动流程模板已归档到 `00_docs/archive_analysis/contest_reproduction_template/`，仅供以后参考。
