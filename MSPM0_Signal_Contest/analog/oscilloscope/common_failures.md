# 示波器常见假象与排查

| 现象 | 快速检查 | 修复 |
|---|---|---|
| 幅度刚好×2/÷2 | 发生器Load、示波器1M/50Ω、探头倍率 | 统一阻抗条件和倍率 |
| 高频幅度变小 | 探头带宽、×1电容、20MHz limit、源/电路带宽 | ×10/有源探头，关limit后复测 |
| 方波变圆 | 系统带宽与上升时间 `tr≈0.35/BW` | 提高全链路带宽/缩短探测回路 |
| 毛刺 | 长地线天线、数字串扰或真实过冲 | 弹簧地/同轴，双点验证 |
| 50Hz | 悬空高阻、地环路、人体耦合 | 短接输入对照、单点共地、屏蔽 |
| 探头一接就停振 | 探头电容/地改变环路 | ×10/低电容有源探头，测缓冲点 |
| 波形忽隐/别频 | 采样率太低、时基过长、触发错误 | 缩短时窗/增存储/检查alias |

## 判别方法

同一节点用 ×10短地与50Ω同轴（若电路允许）两种方法对比；异常只在一种探测方式出现，优先怀疑测量负载。任何地夹连接前确认台式示波器保护地关系，避免短路非隔离节点。
