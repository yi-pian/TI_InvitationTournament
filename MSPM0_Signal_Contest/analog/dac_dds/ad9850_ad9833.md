# AD9850 与 AD9833 现场选型

| 项目 | AD9833 | AD9850 |
|---|---|---|
| 参考时钟/累加器 | 25MHz 常用基准，28bit；官方示例分辨率 0.1Hz@25MHz | 最高 125MHz，32bit；0.0291Hz@125MHz |
| 输出 | 正弦、三角、方波 | 内部10bit DAC正弦+高速比较器方波 |
| 接口 | 3-wire SPI | 40bit 串行或 5×8bit 并行装载；不是普通固定帧 SPI 的直接替代 |
| 供电 | 2.3～5.5V | 3.3V或5V |
| 幅度 | 无通用数字幅度寄存器，需外部控制 | 参考电流/外部后级决定，常用模块不等于任意调幅 |
| 适合 | kHz～低MHz、接口简单、低功耗 | 更高频率与更细频率字、外部滤波要求更高 |

## 选择原则

只需几百 kHz～数 MHz、正弦/三角且 SPI 简单，优先 AD9833 类。需要更高参考时钟/输出频率，评估 AD9850 类。两者都要核对模块晶振、输出滤波、负载与逻辑电平。

## 频率上限不是“半时钟就都好用”

Nyquist 只给数学边界；靠近 `fclk/2` 时镜像、sinc 下垂和滤波难度剧增。实际高质量输出上限由允许 SFDR/THD 决定。
