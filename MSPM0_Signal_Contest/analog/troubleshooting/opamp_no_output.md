# 运放没有输出故障树

1. **电源**：直接量芯片电源脚，不只看电源面板；确认正负/地和去耦。
2. **静态点**：断开输入，给合法中点；输出应在可预测位置。
3. **输入共模/差分**：测两输入脚，不只测外部信号源。
4. **反馈**：断电量 Rf/Rg 连通与阻值；确认不是正反馈、封装脚位没镜像。
5. **输出摆幅/负载**：断开负载；若恢复，查过流/容性负载。
6. **稳定性**：高带宽观察是否其实在振荡；短地探测。
7. **带宽/SR**：降频降幅；若恢复，重新选型。

修复后从低频小信号逐级恢复负载，不一次把完整系统全接回。
