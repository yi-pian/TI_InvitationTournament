# example05 阻抗测量：模块选择与题目定义

## 1. 题目拆分

按 22_X 的赛场顺序，把题目拆成六个可分别 Build 的小题：

1. 选择模块，复制冻结的 `.c/.h` 到 `modules/`。
2. 用同一 Timer 触发双 ADC，同步得到电流、电压数组。
3. 初始化 ST7789，使用 8×16 字库显示一帧数据。
4. 接入 AD9833，先验证 1 kHz、再验证 100 kHz 的外部正弦激励。
5. 复制对数扫频、RMS、阻抗与相位组合段，完成 1 kHz～100 kHz 自动扫频。
6. 扫频结束后识别 R/L/C/RLC，计算谐振频率、带宽和 Q。

每一步都先阅读对应 README，复制代码并 Build；模块 `.c/.h/.inc` 不编辑。第 4 步替代原来的片内 DAC/DDS，AD9833 的幅度和直流偏置由外部模拟前端完成。

## 2. 模块选择

| 功能 | 模块 | 复制到 `modules/` 的文件 | 选择理由 |
|---|---|---|---|
| 双路同步采样 | `02_acquisition/adc_dual_sync` | `signal_dual_adc_mspm0g3507.c/.h`、`signal_status.h` | 同一数组下标对应同一触发时刻 |
| 外部扫频激励 | `12_external_devices/dds/ad9833` | `ad9833.c/.h`、`mspm0_blocking_bus.c/.h` | 外部 28-bit DDS，无 MCU DAC/DMA 波表 |
| 对数扫频表 | `06_generator/frequency_sweep` | `signal_frequency_sweep.c/.h` | 生成 32 点对数频率 |
| 显示 | `12_external_devices/display/st7789` | ST7789 核心、平台层、字库 `.c/.h/.inc` | 题目指定 ST7789、8×16 字库 |

母版原有的 DAC/DDS、键盘、方波等文件都不编辑。DAC/DDS 文件不是本题模块：在 CCS Refresh 后对它们执行 **Exclude from Build**，否则它们会引用已删去的 DAC SysConfig 宏。

## 3. 复制与工程操作顺序

1. 从 `MSPM0_Signal_Contest/12_external_devices/dds/ad9833/` 复制 `ad9833.c/.h`。
2. 从 `MSPM0_Signal_Contest/12_external_devices/00_common/` 复制 `mspm0_blocking_bus.c/.h`。
3. 不修改四个复制文件；用 `Get-FileHash` 对比来源。
4. 在 CCS Project Explorer 右键工程 **Refresh**，确认新增两份 `.c` 已纳入 Build。
5. `.cproject` 已预置 Debug 排除项；确认下列母版旧源显示为 **Excluded from Build**：`signal_dac_dma_mspm0g3507.c`、`signal_dac_wave_table.c`、`signal_dds.c`、`signal_sine.c`、`signal_square.c`、`signal_triangle.c`、`signal_sawtooth.c`、`signal_wave_output_mspm0g3507.c`。它们保留在目录中但不参加本题编译。
6. 只在 `signal_config.h`、`.syscfg`、`main.c` 和步骤文档写题目内容。

## 4. 题目参数与接线角色

| 参数 | 数值 | 说明 |
|---|---:|---|
| 扫频范围 | 1 kHz～100 kHz | `SIGNAL_EXPECTED_MIN_HZ/MAX_HZ` |
| 扫频点数 | 32 | 对数分布 |
| ADC 采样率 | 500 kSPS | 100 kHz 约 5 点/周期 |
| 每帧点数 | 2048 | 两路 DMA 原始码数组 |
| AD9833 MCLK | 25 MHz 默认值 | 必须改为模块晶振丝印/实测值 |
| AD9833 控制 SPI | SPI0：PA12 SCLK、PA9 SDATA、PA8 FSYNC | 独立于屏幕 SPI1，不共用引脚 |
| 屏幕字号 | 8×16 | `TFT_ST7789_FONT_8X16` |

电流通道换算系数必须按前端跨阻增益校准；默认 `3.3/4095` 只为可编译起点。AD9833 的 `VOUT` 也不能直接假定等于旧 DAC 的 1.0 Vpp、1.65 V 偏置输出。

## 5. 与 22_X 的对应关系

现场节奏仍是“先双 ADC，再显示，再激励扫频，再相位与参数计算”。22_X 的李萨如、键盘、PLL 倍频不是本题要求；本题用 AD9833 和串联 RLC 模型替代。
