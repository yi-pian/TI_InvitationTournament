# example05 步骤五：阻抗、相位与 AD9833 自动扫频

## 1. 扫频表

从 `signal_frequency_sweep` README 复制：

```c
const signal_frequency_sweep_config_t sweep_config = {
    SIGNAL_EXPECTED_MIN_HZ, SIGNAL_EXPECTED_MAX_HZ,
    APP_SWEEP_POINTS, true
};
if (SignalFrequencySweep_Generate(&sweep_config, g_frequency_hz,
        APP_SWEEP_POINTS) != SIGNAL_RESULT_OK) while (1) { }
```

`true` 表示对数扫频。`App_RunSweepPoint()` 对每个浮点频率加 0.5 后转为整数 `output_hz`，回写数组，再传给 AD9833；因此显示、相位参考和拟合使用同一个实际请求 Hz。

## 2. 一帧测量的复制顺序

1. 通过 `App_AD9833_SetSine(output_hz)` 调用 README 的 `AD9833_SetOutput()`。
2. 复制双 ADC README 的 `Start`、等待 `IsFinished`、超时 `Stop`。
3. 对两路求均值和 RMS。
4. 对电压、电流做正交相关，求相位差。
5. 计算 `|Z|=Vrms/Irms`、`Zre`、`Zim`。
6. 用 ST7789 8×16 字库刷新当前点数据。

AD9833 没有频率回读，无法取得像旧 DAC DMA 一样的“实际整数周期频率”；驱动的 28-bit FTW 误差很小，故这里以写入模块的整数 `output_hz` 为参考。若 `AD9833_SetOutput()` 失败，显示 `AD9833 ERROR`，不读取 ADC 缓冲区。

## 3. 相位组合代码来源和逐行解释

`App_PhaseDegrees()` 是先补在 `modules/README.md` 第 11 节、再复制到 `main.c` 的应用代码：

```c
float step = 2π * f / Fs;                 /* 每个采样点的参考角增量。 */
for (i = 0; i < N; ++i) {                 /* 遍历已完成 DMA 的一帧。 */
    angle = step * i;                     /* 当前参考正弦角。 */
    sample = raw[i] - mean;               /* 去掉前端直流偏置。 */
    real += sample * cos(angle);          /* 同相相关。 */
    imag += sample * sin(angle);          /* 正交相关。 */
}
phase = atan2(-imag, real) * 180 / π;     /* 得到该通道基波相位。 */
```

电压相位减电流相位得到阻抗相位差；`App_WrapPhase()` 将差值限制到 `[-180,+180]`。这些浮点计算在 DMA 完成后的主循环执行，不放进 ADC/DMA ISR。

## 4. 少量自写逻辑清单

- 将 ADC A/B 分别解释为电流/电压，并用校准宏换算 A/V。
- 将 sweep index、AD9833 整数频率、结果数组和 TFT 坐标连接起来。
- 使用独立 `SPI_AD9833`（SPI0、Mode 2）写 AD9833，不改变屏幕 SPI1 的 Mode 0/CS0。
- 输出或 DMA 失败时显示错误并跳过该点。
- 对有效帧计数，避免上一轮结果参与本轮拟合。

## 5. 自写代码逐段说明（对应 `main.c`）

| 段落 | 自写内容 | 作用 |
|---|---|---|
| 大步骤 3 | `App_AD9833_Init`、`App_AD9833_SetSine` | 直接使用 README 调用；SPI0 Mode 2 由 SysConfig 固定。 |
| 大步骤 4 | `App_PhaseDegrees`、`App_WrapPhase` | 去均值、正交相关、`atan2` 求相位并环绕。 |
| 大步骤 5 | `App_MeasureFrame` | 复制 ADC 启动/等待闭环后计算 RMS、`|Z|`、`Zre/Zim`。 |
| `App_RunSweepPoint` | AD9833 设频、错误处理、采样和页面刷新连接。 |
| `SysTick_Handler` | 只累计结果保持时间，不做浮点、DMA 或 SPI。 |

模块驱动、DMA ISR、AD9833 频率字生成、TFT SPI 和对数频率表都不是自写。
