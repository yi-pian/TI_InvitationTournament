# example05 步骤三：ST7789 与 8×16 字库显示

## 1. 选择和复制

按 ST7789 README 复制核心、平台和字库：

```text
signal_tft_st7789.c/.h
signal_tft_st7789_mspm0g3507.c/.h
signal_tft_st7789_font.c/.h
signal_tft_st7789_font_data.inc
signal_status.h
```

`.inc` 字库文件也要加入 CCS 工程；本题所有标签、单位和数字均用 `TFT_ST7789_FONT_8X16`。

## 2. SysConfig

完全沿用 README 的 SPI profile：SPI1、PB9 SCLK、PB8 MOSI、PB6 CS0、PB15 DC、PB12 BLK；
8 bit、MSB first、Mode 0。RESET 使用屏模块自带/平台层默认处理，偏移传 0、0。

本题没有修改 ST7789 README 的引脚和实例名。AD9833 改用独立 SPI0（PA12/PA9），因此屏幕
SPI1 不与 AD9833 共用任何信号线。保存后 Generate，核对 `SPI_TFT_INST`、`GPIO_TFT_CTRL_*` 宏。

## 3. 从 README 复制的初始化和显示

```c
if (SignalTFTST7789_MSPM0_Init(&g_tft, TFT_ST7789_ROTATION_270,
        0U, 0U) != TFT_ST7789_OK) {
    while (1) { }
}
(void)TFT_ST7789_FillScreen(&g_tft, TFT_ST7789_BLACK);
(void)TFT_ST7789_DrawString(&g_tft, 4, 2, "IMPEDANCE METER",
    TFT_ST7789_FONT_8X16, TFT_ST7789_CYAN, TFT_ST7789_BLACK, false, false);
```

逐行说明：平台入口绑定 SysConfig 生成的 SPI/GPIO；横屏旋转 270 度得到 320×240 显示；
先清黑屏再画固定标题。`App_Text()`、`App_ClearRow()`、`App_LabelFloat()` 是从该调用
形状写出的薄包装，只负责坐标、颜色和局部清除。

## 4. 页面安排

扫频中显示：当前频率、`Vrms`、`Irms`、`|Z|`、相位差和进度条；扫频结束显示：
`TYPE:R/L/C/RLC`、元件值、`F0`、`BW` 和 `Q`。每行高度 16 像素，避免用大字体覆盖旧数字。
`FillScreen()` 只在上电和重扫时调用；数值更新用 `FillRect` 清除单行，符合 README 的局部刷新建议。

## 5. 本步验收

未接模拟输入时先确认黑底标题和 8×16 ASCII 能显示；若白屏/花屏，按 README 顺序检查
供电、共地、RST、DC、CS、SPI mode 和偏移，不能先改字库或算法。
