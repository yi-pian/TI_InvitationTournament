# example05 步骤六：R/L/C 识别、谐振频率、带宽和 Q

## 1. 串联模型

对每个有效扫频点保存：`f`、`Vrms`、`Irms`、`|Z|`、`Zre`、`Zim`、`phase`。串联模型为：

```text
Z(f) = R + j(2πfL - 1/(2πfC))
```

因此对 `Zre=R` 求平均，对 `Zim` 用自变量 `w=2πf` 和 `u=1/w` 做两参数最小二乘：

```text
Zim = w·L + u·(-1/C)
```

`App_FitSeriesModel()` 就是本段 README 补充代码的逐字实现，求解后只接受 `L>0`、
`C>0` 的结果；没有足够有效点时保持 0。

## 2. R/L/C 判断

1. 扫频相位绝对值平均不超过 12°：`TYPE:R`，显示 `R`，单位 Ohm。
2. 平均相位为正：`TYPE:L`，显示 `L`，单位 H。
3. 平均相位为负：`TYPE:C`，显示 `C`，单位 F。
4. 正、负相位都出现：显示 `TYPE:RLC`，同时在底部显示拟合的 L、C。

最后一种是“串联 RLC 网络”的组合状态，并不违背题目要求的 R/L/C 自动判断；显示中仍
给出主导类型和对应元件值，若只接单个元件，不会跨过相位零点。

## 3. 谐振、带宽和 Q

- 有效的 L/C 拟合值在 1 kHz～100 kHz 内时，用 `f0=1/(2π√LC)`；否则取扫描中 `|Z|`
  最小的点。
- 串联谐振的电阻基准是拟合 `R`；阈值为 `sqrt(2)*R`。
- 从最小阻抗点向左右寻找阈值交点，使用相邻扫频点线性插值，得到 `fL`、`fH`。
- `BW=fH-fL`，若两侧都找到则 `Q=f0/BW`，否则显示 `Q=0`。

## 4. 边界保护

`App_DrawAnalysis()` 先检查有效点数和最小阻抗下标；没有有效点只显示 `NO VALID DATA`。
电流 RMS 小于 `1e-9 A` 时阻抗置零，避免除零；拟合行列式过小时不使用数值不稳定的 L/C。
这些保护是少量应用逻辑，模块文件完全未改动。

## 5. 自写代码逐行说明（对应 `main.c`）

| 行号 | 自写内容 | 作用 |
|---:|---|---|
| 175～213 | `App_FitSeriesModel` | 遍历有效点，令 `w=2πf`、`u=1/w`，用两参数最小二乘求 `L` 和 `-1/C`；行列式过小时放弃拟合。 |
| 215～221 | `App_InterpolateCrossing` | 对半功率阈值两侧的相邻扫频点做线性插值，避免带宽只能取离散点间隔。 |
| 224～325 | `App_DrawAnalysis` | 找最小阻抗点，按相位正负判断类型，计算拟合谐振频率、`√2R` 交点、带宽和 Q，并逐行显示结果。 |
| 258～279 | 类型和值选择 | `R` 显示拟合电阻，正相位显示 `L`，负相位显示 `C`；同时出现正负相位时标记 `RLC`。 |
| 283～308 | `F0/BW/Q` | 有效 `L/C` 时用解析谐振频率，否则用最小 `|Z|` 点；两侧交点齐全才计算 `Q=f0/BW`。 |

逐行执行顺序是“先保护有效点 → 再拟合 → 再分类 → 再算谐振/带宽/Q → 最后刷屏”，
没有把这些浮点运算放进 ADC/DMA 中断。

## 6. 屏幕最终布局

```text
SWEEP DONE
Vrms / Irms / |Z| / Phase
TYPE:R/L/C/RLC   Value
F0              BW
Q               L/C（RLC 时）
```

单位分别为 V、A、Ohm、deg、Ohm/H/F、kHz、kHz、无量纲 Q；所有字符为 ST7789 8×16 字库。
