# example06-02：ST7789 显示与 8×16 字库

## 比赛动作

按 `12_external_devices/display/st7789/README.md` 复制核心、MSPM0G3507 平台层和字库
三件套（`.c/.h/.inc`）。SysConfig 配置 `SPI_TFT=SPI1`：SCLK PB9、MOSI PB8、硬件 CS
PB6；`GPIO_TFT_CTRL`：DC PB15、BLK PB12。README 的初始化表和平台绑定未改。

## main 复制与自写内容

- 复制 README 的 `SignalTFTST7789_MSPM0_Init()` 调用形状（`main.c:263-268`）。
- 复制字库 API 的调用形式，全部选择 `TFT_ST7789_FONT_8X16`
  （`main.c:196-224`）。
- `App_DrawMeasurement()` 的坐标、标签和波形绘制是题目应用逻辑；显示区为 x=4、
  y=76、312×150，波形使用高度的 40% 上下范围，即约 80% 绘图区。

## 逐段解释

- 203-204：每帧清屏，避免旧测量值残留。
- `main.c` 的局部刷新函数：用 8×16 字库显示频率 F、峰峰值 VPP、周期数 N；相位字段已取消。
- 224：调用波形绘图；ST7789 驱动内部负责窗口、RGB565 和 SPI 发送。

模块源码没有加中文字模，也没有改 SPI 驱动。
