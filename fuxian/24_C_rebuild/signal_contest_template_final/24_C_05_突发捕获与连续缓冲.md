# 24_C-05 突发捕获与连续缓冲

双 ADC 连续多缓冲来自模块 README。main 的题目逻辑检测 1-5 ms 突发，锁定后显示一次并停止覆盖。

逐行解释：`burst_trigger_latched` 记住 ADC1 曾看到边沿；模拟阈值循环在 ADC0 中找真实首尾；首尾索引差除以 Fs 得持续时间；若尾部碰到最新帧边界则等待下一块补齐后沿；满足 0.9-5.35 ms 才置 `detected`；检测成功后 Stop，保证单次波形留在屏幕。进入 `BURST ARMED` 时先启动三缓冲连续采集，再更新 ST7789 的两个状态字段，避免较慢的整页刷屏制造采集盲区。ADC1 只触发，幅度和边界都来自 ADC0。
