# 24_C-06 ST7789 波形显示

本阶段新增并从集成库复制 `01_bsp/tft_waveform_st7789`。它的 README 已包含复制文件、ST7789 SysConfig、最小配置和局部刷新做法。main 直接声明 `signal_tft_waveform_st7789_config_t` 并调用 `SignalTFTWaveformST7789_Draw`，没有 ILI9341 映射。

自写配置逐行解释：`x/y/width/height` 指定原图框内部；`mode` 在周期信号用抽点连线、突发用 min/max 包络；固定量程为 -2.75 到 2.75 V；四个颜色字段保持原界面；网格设 4x5；`clear_background=true` 只清内部；`draw_border=false` 因为蓝色边框已在静态界面画一次；`draw_baseline=true` 重画零线。main 不再写坐标映射、抽点或包络循环。
