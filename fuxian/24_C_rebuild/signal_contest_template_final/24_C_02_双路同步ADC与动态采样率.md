# 24_C-02 双路同步 ADC 与动态采样率

从 dual ADC README 复制 Init/Start/StartContinuous/IsFinished/SetSampleRate 调用，从 timer capture README 复制 Init/Start/GetResult。ADC0 采波形，ADC1 采门控/比较信号，两路由同一 TIMG0 事件触发。

自写动态 Fs 逐行解释：先读取 capture 频率；`SelectSampleRate` 根据频率选择目标点数每周期；下限判断防止 Fs 太低；上限判断限制为 ADC 模块允许值；如果 PB2 暂时没有有效 capture，则使用 FFT 基频作为备用频率源；目标值写入 `pending_sample_rate_hz`；只有 DMA 完成后才调用 SetSampleRate；最后读取实际配置率保存到 buffer 元数据，避免用错 Fs 计算时间轴。这样 100 Hz 在初始硬件测频尚未锁定时也会逐帧切到约 20 kS/s，窗口可以容纳三个周期。
