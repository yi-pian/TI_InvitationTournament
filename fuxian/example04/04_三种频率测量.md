# 阶段四：三种频率测量

## 硬件法：Comparator + Timer Capture

Comparator、Timer Capture 与 SysConfig 路由仍由现有正式模块负责。CH1 必须同时接 ADC 输入和 PA27 比较器输入；只接 ADC 时硬件测频不会有结果。

```c
SignalComparatorZeroCross_MakeConfig(1.65f, 0.005f, &comparator_config);
SignalTimerCapture_MSPM0_Init(&capture_config);
SignalTimerCapture_MSPM0_Start();
SignalTimerCapture_MSPM0_GetResult(&g_capture_frequency);
```

TIMG7 的中断应启用 `CC0_DN`、`CC1_DN` 和 `ZERO`，以匹配现有 MSPM0 捕获驱动读取的中断源。

## ADC 时域法：去直流、过零和插值

冻结的 Remove DC 与 Multi-Cycle-Average 封装已删除。`main.c` 按 `remove_dc.md` 直接使用 CMSIS 求均值和偏移，之后仍使用正式过零及插值模块：

```c
arm_mean_f32(g_calibrated, SIGNAL_SAMPLE_COUNT, &g_mean_v);
arm_offset_f32(g_calibrated, -g_mean_v, g_centered, SIGNAL_SAMPLE_COUNT);
SignalZeroCross_Process(g_centered, SIGNAL_SAMPLE_COUNT, &zero_config,
    g_zero_events, SIGNAL_ZERO_EVENT_CAPACITY, &zero_result);
SignalZeroCrossInterpolation_Process(g_centered, SIGNAL_SAMPLE_COUNT, 0.0f,
    g_zero_events, zero_result.event_count, g_crossing_positions,
    SIGNAL_ZERO_EVENT_CAPACITY, &interpolation_result);
```

旧工程的多周期平均返回值从未写入页面或全局状态，因此已连同未使用的兼容函数删除；过零检测、亚采样插值、硬件 Timer 测频和频谱测频均保持。

## FFT 法

FFT 路线在 `App_Spectrum()` 完成：去直流、窗函数、CMSIS Q15 CFFT、幅值、主峰和抛物线插值。页面继续显示硬件捕获和 FFT 的频率结果；所有频率计算使用 `g_effective_sample_rate_hz`，而不是固定标称采样率。
