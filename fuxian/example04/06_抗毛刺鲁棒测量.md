# 阶段六：抗毛刺鲁棒测量

## 1. 复制内容

复制 `mad`、`median_filter`、`hampel`、`robust_peak_to_peak`、`robust_rms`。按键 `5/6/7` 分别设置 RAW、Median、Hampel。

## 2. 处理代码

```c
const float *input = g_calibrated;
if (g_filter == APP_FILTER_MEDIAN) {
    SignalMedianFilter_Process(g_calibrated, g_voltage,
        SIGNAL_SAMPLE_COUNT, 5U, g_workspace, SIGNAL_SAMPLE_COUNT);
    input = g_voltage;
} else if (g_filter == APP_FILTER_HAMPEL) {
    SignalHampel_Process(g_calibrated, g_voltage, SIGNAL_SAMPLE_COUNT,
        &hampel_config, g_workspace, SIGNAL_SAMPLE_COUNT, &hampel_result);
    input = g_voltage;
}
SignalMAD_Process(input, SIGNAL_SAMPLE_COUNT, g_workspace,
    SIGNAL_SAMPLE_COUNT, &g_mad);
SignalRobustPeakToPeak_Process(input, SIGNAL_SAMPLE_COUNT,
    &vpp_config, g_workspace, SIGNAL_SAMPLE_COUNT, &g_robust_vpp);
SignalRobustRMS_Process(input, SIGNAL_SAMPLE_COUNT, &rms_config,
    g_workspace, SIGNAL_SAMPLE_COUNT, &g_robust_rms);
```

逐行解释：先让 `input` 指向未经处理的校准数组；选择 Median 时用 5 点中值替换孤立尖峰；选择 Hampel 时用局部中位数和 MAD 判断离群点；随后 MAD 给出当前数据的离散尺度；Robust Vpp 和 Robust RMS 使用分位数/稳健权重，避免单个毛刺主导结果。

## 3. README 差异和验证

模块调用和参数含义按 README；本题自写的是键盘选择和三种结果并排显示。Hampel 会删除被判为异常的尖峰，真实脉冲信号不能盲目使用；比赛时应先在 RAW 页面确认毛刺，再比较 Median/Hampel 页面。当前只做源码级验证，未注入实板 ADC 毛刺。
