# 阶段二：可编程波形发生

## 1. 复制模块和 README 代码

从集成库复制 `06_generator/wave_output` 的 `signal_wave_output_mspm0g3507.c/.h`、
README、最小示例和完整示例，并按依赖清单复制 `dac_wave_table`、`dds`、`dac_dma`、
`sine`、`square`、`triangle`、`sawtooth` 的 `.c/.h`。main 只复制统一模块的初始化和
四个三参数接口调用；波表生成、幅值换算、DDS、整周期 DMA 已封装在模块中，底层正式
模块文件没有修改。

## 2. 自写组合逻辑

`App_ApplyWaveform()` 是本阶段的自写函数，但函数内部只负责把当前页面参数转交给
README 中的统一接口。核心代码：

```c
SignalWaveOutput_SineWithOffset(
    (float)g_output_frequency_hz, (float)g_amplitude_mv / 1000.0f,
    (float)g_offset_mv / 1000.0f);
```

逐行解释：

1. `g_output_frequency_hz` 转成浮点 Hz，作为第一个参数。
2. `g_amplitude_mv / 1000.0f` 把页面保存的 mV 转成 Vpp，作为第二个参数。
3. `g_offset_mv / 1000.0f` 把页面保存的 mV 转成偏置电压，作为第三个参数。
4. `SignalWaveOutput_SineWithOffset` 按 README 完成波表、DDS 和 DAC DMA 整周期输出；
   方波、三角波、锯齿波只需替换为对应的 `...Square...`、`...Triangle...`、
   `...Sawtooth...` 接口。

模块内部按 `output_count = round(update_rate / frequency)` 选择整数点数，因此 DMA 缓冲
首尾相接，减少波形残影；返回结果中的 `actual_frequency_hz` 是整数周期约束后的实际频率。

## 3. 键盘参数逻辑

键 `1~4` 直接选择波形；`B/C/*` 进入频率、幅度、偏置数字输入；`#` 提交，`D` 取消。这里 AMP 按 Vpp 输入，main 额外检查 `offset ± Vpp/2` 不越过 0～3.3 V，避免波表生成器返回越界。数字解析、范围检查和页面状态机是自写代码。提交成功后置 `g_wave_dirty=true`，主循环检测该标志并重新调用 `App_ApplyWaveform()`，这样输入参数一定会真正作用到 OUT。

## 4. SysConfig 差异

波形算法模块不新增外设；DAC DMA README 的 TIMG、DMA 和 DAC 配置已合并到阶段一 profile。没有修改 DAC DMA 模块源码。

## 5. 验证边界

源码已接通 `Wave Table -> DDS -> DAC DMA`，但尚未实测 OUT 幅度、偏置、频率和 20 kHz 失真；100 kSPS 时高频每周期点数有限，必须上板确认。
