# 阶段三：CH1 基本测量

## 数据链

```text
CH1 ADC DMA 原始码 -> ADC 转电压 Recipe -> 两点增益/偏置校准
-> CMSIS Mean / Min / Max / RMS -> Vpp、AC RMS、总体标准差、削顶提示
```

双 ADC 的启动和等待仍由 `signal_dual_adc_mspm0g3507` 负责；DMA 完成后，`main.c` 以实际配置采样率继续后续测量。

```c
SignalDualADC_SetSampleRate(g_sample_rate_hz);
SignalDualADC_Start(g_raw_ch1, g_raw_ch2, SIGNAL_SAMPLE_COUNT);
while (!SignalDualADC_IsFinished()) { __WFI(); }
g_effective_sample_rate_hz = SignalDualADC_GetConfiguredRate();
```

## 当前 Recipe 实现

`main.c` 不再复制冻结的 `signal_adc_to_voltage`、`signal_mean`、`signal_rms` 等兼容封装，直接采用 `MSPM0_Signal_Contest/00_docs/recipes` 的现行入口：

```c
App_RecipeADCToVoltage(g_raw_ch1, g_voltage, SIGNAL_SAMPLE_COUNT,
    SIGNAL_ADC_VREF_V, APP_ADC_MAX_CODE, 1.0f, 0.0f);
SignalADCGainOffsetCalibration_Apply(g_voltage, g_calibrated,
    SIGNAL_SAMPLE_COUNT, &g_adc_calibration);

arm_mean_f32(g_calibrated, SIGNAL_SAMPLE_COUNT, &g_mean_v);
arm_min_f32(g_calibrated, SIGNAL_SAMPLE_COUNT, &g_min_v, &min_index);
arm_max_f32(g_calibrated, SIGNAL_SAMPLE_COUNT, &g_max_v, &max_index);
g_vpp_v = g_max_v - g_min_v;
arm_rms_f32(g_calibrated, SIGNAL_SAMPLE_COUNT, &g_rms_v);
arm_offset_f32(g_calibrated, -g_mean_v, g_workspace, SIGNAL_SAMPLE_COUNT);
arm_rms_f32(g_workspace, SIGNAL_SAMPLE_COUNT, &g_ac_rms_v);
```

- `adc_to_voltage.md` 保持原有的 12-bit、3.3 V、比例 1、偏移 0 的换算。
- `mean.md`、`minmax.md`、`vpp.md`、`rms.md` 直接调用 CMSIS-DSP，显示的 DC、Min、Max、Vpp、总 RMS 单位仍为 V。
- `ac_rms.md` 先减本帧 DC，再计算 RMS；临时数组为 `g_workspace`，不覆盖已校准的原始电压。
- 原总体标准差显示保留 Welford 单遍计算，以维持“总体标准差”定义并避免大偏置下的消去误差。
- `clipping_detect.md` 在滤波前按原阈值 0.02 V 和 3.28 V 计数；任一点触边就显示 `CLIPPING`。

## 验证边界

基本算法没有额外 SysConfig 资源；仍需在 CCS 生成后确认 ADC0/ADC1、DMA_CH0/DMA_CH2 和 TIMG0 的配置，并在实板以已知直流电压和正弦波验证量程与校准结果。
