# 阶段九：系统校准与最终验证

## 1. ADC Gain/Offset 两点校准

复制 `adc_gain_offset_calibration`。校准页 D 键先把 DAC 设为 0.5 V，等待模拟输出稳定，采集 CH1 多点并求均值；再设为 2.5 V，重复采集；最后调用：

```c
SignalADCGainOffsetCalibration_Compute(low_mean.mean_value, 0.5f,
    high_mean.mean_value, 2.5f, &g_adc_calibration);
```

逐行解释：`low_mean.mean_value` 是 ADC 对低点的实测平均电压；`0.5f` 是低点真值；`high_mean.mean_value` 是高点实测平均电压；`2.5f` 是高点真值；最后一个地址用于写回 `corrected = gain * measured + offset` 的两个校准参数。main 中生成校准直流码时使用 `normalized=1、offset=0、amplitude=目标电压/VREF`，这样波表换算结果分别确实是 0.5 V 和 2.5 V，而不是把 `normalized=0` 误当成直流输出。后续 CH1/CH2 电压数组都经过 `SignalADCGainOffsetCalibration_Apply`。

## 2. Channel Delay 校准

把同一个正弦同时接 CH1、CH2，先运行两路 Sine Fit 得到相位，再调用：

```c
g_channel_phase_deg = g_fit3_ch2.phase_deg - g_fit3.phase_deg;
SignalChannelDelayCalibration_Compute(g_channel_phase_deg, 0.0f,
    (float)g_output_frequency_hz, &g_delay_calibration);
```

第一行计算 B-A 实测相位；第二行把该实测值与理论 0° 比较；第三行用校准频率换算成 B 相对 A 的固定延迟秒数。主循环以后会调用 `SignalChannelDelayCalibration_Apply`，把实测相位和固定延迟写成 `g_corrected_phase_deg`，因此 CAL 页面显示的是补偿结果。校准频率必须已知且延迟小于半周期，否则相位绕回会产生整周歧义。

## 3. SysConfig 和 README 一致性

两类校准算法不新增外设；所需 DAC 回环、ADC 双通道和 Timer/FFT 资源均来自前面阶段。README 要求的等待稳定步骤在本题中用有限忙等待补上，实际等待长度仍需根据外部 RC、运放和回环线实测调整。

## 4. 最终验收清单

- 频率 200 Hz、1 kHz、10 kHz、20 kHz 四点分别比较 TIMER/ZERO/FFT/FIT。
- 正弦输入观察基波、H2、H3、THD、SNR、SFDR 和四种窗函数变化。
- 人为加入尖峰，比较 RAW、Median、Hampel 的 Vpp/RMS。
- 用已知 DDS 微弱回环比较 FFT 与 Lock-In 的幅值、相位。
- 输入单次脉冲或猝发波，确认触发前后波形及 D 键复现。
- 执行 0.5 V/2.5 V ADC 校准和 CH1/CH2 延迟校准。
