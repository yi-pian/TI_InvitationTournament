# example03 步骤 03：双路有限帧采集

## 1. 模块选择

本阶段从集成库复制 `signal_dual_adc_mspm0g3507.c/.h`，使用两个 ADC 同步采样 CH1、CH2。采样缓冲区由 main 提供：

```c
static uint16_t g_raw_a[APP_SAMPLE_COUNT];
static uint16_t g_raw_b[APP_SAMPLE_COUNT];
```

本阶段不再使用旧的 `signal_adc_pingpong_dma` 和 `signal_adc_ring_buffer`，因为本题不做猝发检测和连续事件缓存，改为和 `example01` 一样的一帧采集流程。

## 2. SysConfig

沿用原 SysConfig：

- CH1 ADC：PA25；
- CH2 ADC：PA17；
- 两个 ADC 由同一个定时器触发；
- DMA 通道分别连接两个 ADC；
- DMA 完成中断打开；
- 采样频率初始为 100 kHz。

在 `SignalDualADC_Init()` 后复制 DMA 中断使能代码：

```c
DL_DMA_enableInterrupt(DMA,
    DL_DMA_INTERRUPT_CHANNEL0 | DL_DMA_INTERRUPT_CHANNEL1);
```

这段不是模块文件修改，而是比赛 main 中必须补充的初始化代码。

## 3. main 采集代码

```c
if (SignalDualADC_Start(g_raw_a, g_raw_b,
        APP_SAMPLE_COUNT) == SIGNAL_RESULT_OK) {
    while (!SignalDualADC_IsFinished()) {
        __WFI();
    }
    App_DrawWaveforms();
}
```

逐行说明：

- `SignalDualADC_Start(...)`：启动一帧双路同步 DMA 采样；
- `g_raw_a/g_raw_b`：分别保存 CH1、CH2 的 ADC 原始码；
- `APP_SAMPLE_COUNT`：本帧采集 256 点；
- `SignalDualADC_IsFinished()`：查询两个 DMA 是否都完成；
- `__WFI()`：等待中断期间休眠，不占用 CPU；
- 采样完成后调用 `App_DrawWaveforms()`，因此不会在 DMA 正在写入时绘图。

## 4. 与原猝发方案的区别

旧方案使用连续块、RingBuffer 和猝发门限统计；本题改为持续重复的有限帧采集。每帧完成后立即显示 CH1、CH2，适合观察连续周期信号，避免短猝发只落在单个采集窗内却无法稳定显示的问题。
