# example03 步骤 05：ST7789、网格和矩阵键盘

## 1. 复制的模块内容

从集成库复制以下文件到工程 `modules`：

- `signal_tft_st7789.c/.h`；
- `signal_tft_st7789_mspm0g3507.c/.h`；
- `signal_tft_st7789_font.c/.h`；
- `signal_tft_st7789_font_data.inc`；
- `signal_matrix_keypad_4x4.c/.h`。

main 只复制模块 README 中给出的初始化和绘图 API 调用，不修改任何模块 `.c/.h` 文件。

## 2. 键盘功能

| 按键 | 功能 |
|---|---|
| A | Y 轴量程减小一档 |
| B | Y 轴量程增大一档 |
| C | X 轴时间范围减小一档，同时提高采样率 |
| D | X 轴时间范围增大一档，同时降低采样率 |
| 1 | 只显示 CH1 |
| 2 | 只显示 CH2 |
| 3 | 同时显示 CH1 和 CH2 |

`SysTick_Handler()` 每 5 ms 调用一次 `SignalMatrixKeypad4x4_ReadNewSymbol()`，中断只把按键放入队列；屏幕刷新和坐标修改均在 main 中执行。

去直流没有伪造一个 `.c/.h` 模块：集成库中该功能当前只有正式的
`remove_dc.md` 配方，因此按照比赛步骤直接复制其中的
`arm_mean_f32()` + `arm_offset_f32()` 代码，并在 main 中分别处理 CH1、CH2。

## 3. 自编按键逻辑

```c
if (symbol == 'A') {
    if (g_y_range_index > 0U) --g_y_range_index;
} else if (symbol == 'B') {
    if (g_y_range_index + 1U < APP_Y_RANGE_COUNT) ++g_y_range_index;
} else if ((symbol == 'C') || (symbol == 'D')) {
    /* 修改 X 档位并调用 SignalDualADC_SetSampleRate。 */
}
```

逐行说明：

- `g_y_range_index`：Y 轴档位数组下标；
- `> 0U`：防止继续减小导致数组越界；
- `+1U < APP_Y_RANGE_COUNT`：防止继续增大导致数组越界；
- C/D 修改 `g_x_range_index` 后，根据 256 点和目标时间范围计算采样率；
- `SignalDualADC_SetSampleRate()`：把新的采样率写入双 ADC 定时器；
- 当前正在采集时模块会返回 BUSY，按键逻辑不会破坏正在进行的采样。

## 4. 自编网格代码

`App_DrawGrid()` 用 4 个水平分割线和 5 个竖直分割线构成网格；`App_DrawGridUnits()` 计算并显示：

```text
YDIV = Y 总范围 / 4
XDIV = X 总时间 / 5
```

例如 Y 轴为 `±3.5 V`、X 轴为 `2.56 ms` 时，屏幕显示：

```text
YDIV:1.75V    XDIV:512us
```

这些都是 main 中少量的界面组合逻辑，ST7789 和矩阵键盘模块本身没有改动。
