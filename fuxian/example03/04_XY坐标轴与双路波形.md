# example03 步骤 04：XY 坐标轴与双路波形显示

## 1. 屏幕布局

屏幕横屏显示：

- 黄色：CH1；
- 青色：CH2；
- 蓝色外框：波形区域；
- 蓝色横线：0 V 水平轴；
- 蓝色竖线：时间中心轴；
- 灰蓝色细线：5 列、4 行网格；
- 底部：每格 Y 电压和 X 时间单位。

ST7789 初始化使用与 `example01`、`24_C_rebuild` 相同的 `TFT_ST7789_ROTATION_270`。

## 2. Y 轴量程

Y 轴固定档位为：

```text
±0.5 V、±1.0 V、±1.5 V、±2.0 V、±2.5 V、±3.0 V、±3.5 V
```

默认是 `±3.5 V`。四行网格把整个 Y 范围分成四格，因此默认每格：

```text
7.0 V / 4 = 1.75 V/div
```

`App_MapY()` 根据当前量程把去直流后的 0 V 映射到水平中轴，并把结果限制在边框内：

```c
float32_t range_voltage = (float32_t)g_y_range_tenth[g_y_range_index] / 10.0F;
int32_t y = center - (int32_t)(centered_voltage * (float32_t)half_height /
    range_voltage);
if (y < APP_PLOT_Y + 1) y = APP_PLOT_Y + 1;
if (y > APP_PLOT_Y + APP_PLOT_H - 2) {
    y = APP_PLOT_Y + APP_PLOT_H - 2;
}
```

- `centered_voltage`：Remove DC 后的电压值，单位 V；
- `range_voltage`：当前 Y 轴的正向量程，例如 ±3.5 V 时为 3.5 V；
- `center`：屏幕水平中线；
- 两个 `if`：防止曲线覆盖蓝色边框。

## 3. X 轴量程

X 轴全屏时间范围为：

```text
1.28 ms、2.56 ms、5.12 ms、10.24 ms
```

本工程采集 256 点，因此对应采样率分别为：

```text
200 kHz、100 kHz、50 kHz、25 kHz
```

5 列网格的每格时间由 `XDIV = X 全屏时间 / 5` 计算。例如默认 2.56 ms 时：

```text
XDIV = 512 us/div
```

按键改变 X 档位后，main 调用 `SignalDualADC_SetSampleRate()`，下一帧采集自动使用新采样率。

## 4. 波形绘制

`App_DrawChannel()` 参考 `example01`，将 256 个采样点压缩为 220 个相邻显示点，再调用模块提供的 `TFT_ST7789_DrawLine()` 连接相邻点。坐标轴和网格只在静态界面初始化时绘制一次；后续帧保存上一帧曲线坐标，只擦除旧曲线并恢复其下方的黑色、网格线或坐标轴颜色，再绘制新曲线。

屏幕显示使用独立缓存 `g_display_a/g_display_b`。ADC 仍然连续采集，但只有当显示计时达到 500 ms 时才把最新缓存画到屏幕，因此每幅波形保持约 0.5 s，不会因每个采样帧都重画而闪烁。

绘制前先把 ADC 码转换为电压，再按 Remove DC README 的代码复制以下 CMSIS-DSP 片段：

```c
#include "arm_math.h"

float32_t removed_dc_v;
arm_mean_f32(input, n, &removed_dc_v);
arm_offset_f32(input, -removed_dc_v, output, n);
```

本工程对两路分别执行 `arm_mean_f32()` 和 `arm_offset_f32()`，输入输出使用各自的显示缓存（允许原地处理）。随后 `App_MapY()` 直接使用去直流后的浮点电压，因此不再由 main 自己编写平均值求和函数，也不依赖固定的 2048 中点。这样可以去除两路各自的直流偏置，使波形围绕 0 V 中线显示。

## 5. 去直流代码逐行解释

```c
g_display_a[index] = (float32_t)g_raw_a[index] * 3.3F / 4095.0F;
```

- 读取 CH1 的 12 位 ADC 码；
- 转为 `float32_t` 后乘以 3.3 V 满量程；
- 除以 4095，得到当前采样电压。

```c
arm_mean_f32(g_display_a, APP_SAMPLE_COUNT, &removed_dc_a);
```

- 按 README 调用 CMSIS-DSP 的平均值函数；
- 求出这一帧 CH1 的直流分量，写入 `removed_dc_a`。

```c
arm_offset_f32(g_display_a, -removed_dc_a,
    g_display_a, APP_SAMPLE_COUNT);
```

- 给每个采样点加上“负的平均值”；
- 输入和输出都传 `g_display_a`，所以直接原地完成去直流；
- 去直流后的结果仍以伏特为单位。

CH2 的三行代码完全相同，只是把缓存和结果变量换成 `g_display_b`、`removed_dc_b`。这些算法调用是从 `remove_dc.md` 复制的；ADC 码到电压的两行赋值、两路缓存组织和绘图映射属于本题必要的少量组合逻辑。
