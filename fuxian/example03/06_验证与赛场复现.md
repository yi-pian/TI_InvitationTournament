# example03 步骤 06：验证与赛场复现

## 复现顺序

1. Import CCS 工程，确认 `modules/` 中每个 `.c` 都加入工程且没有 `Exclude from Build`。
2. 打开 `signal_contest_template.syscfg`，核对 ADC0/ADC1、PA25/PA17、DMA_CH0/CH1、TIMG0、ST7789 SPI 和矩阵键盘 GPIO；Generate 后只读检查生成宏。
3. 先只运行 ST7789 静态界面，确认蓝色边框和背光正常。
4. 给 A/B 接同频方波或脉冲串，确认每 256 点更新一次，A/B 页分别能显示。
5. 按 A/B 改变门限，观察 `g_burst_length` 与 `g_high_count` 的变化；按 C/D 确认页面切换且蓝框不闪烁。
6. 用示波器或逻辑分析仪核对 Timer 触发频率、DMA 块边界和两路采样同步性；观察 Ring Buffer 满时是否出现 overrun。

## 检查边界

已完成源码级 API、模块复制清单和 SysConfig 资源关系检查。当前环境没有 CCS/TI Arm Clang 的完整构建链，也没有连接目标板，因此不能声称编译、DMA 实时性、屏幕刷新或实测门限精度通过。
