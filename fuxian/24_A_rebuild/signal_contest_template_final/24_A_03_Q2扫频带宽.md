# 24_A-03 Q2 扫频带宽

复制 ADC DMA README 的 Init/SetSampleRate/Start/IsFinished 调用和 AD9850 改频调用。main 的扫频循环每次设置频率、等待稳定、采集三帧并求 AC RMS；比值第一次跨过 0.70710678 时，用前后两个频点线性插值得到 -3 dB 频率。

逐行解释自写部分：`previous_ratio` 保存上个点；`ratio` 是当前响应/低频参考；条件判断负责发现阈值跨越；插值行计算阈值在两个 ratio 之间所占比例；最后按此比例换算频率。ADC 触发、DMA 搬运和 DDS 写入均来自模块。
