# 三个预测信号类题目总览

这三个 example 都以 MSPM0G3507 / CCS / SysConfig 为母版，屏幕统一使用 ST7789，键盘统一使用 4×4 矩阵键盘。每个题目都拆为六份文档：模块选择、硬件/采集、核心算法或数据流、显示与键盘、验证复现。

## 题目一：双通道可调信号分析仪（example01）

双路同步 ADC 采集 X/Y，ST7789 显示波形，矩阵键盘改变门限和采样率，并用上升过零插值测相位差。覆盖双 ADC、Timer/Event、DMA、过零相位、局部刷新和固定引脚键盘。

## 题目二：扫频网络幅频/相频测试仪（example02）

DDS + DAC DMA 输出 500 Hz 到 8 kHz 扫频激励，双 ADC 同步采集网络输入/输出，ST7789 绘制幅频或相频曲线，矩阵键盘选择曲线、重扫和采样率。覆盖 DDS、DAC12、DAC DMA、频率扫频、Vpp、相位、曲线绘制以及 DMA 通道冲突处理。

## 题目三：猝发/调制双路信号识别仪（example03）

双路连续 ADC 采集，Ping-Pong 轮转完整块，Ring Buffer 保存门限事件，计算猝发长度和高门限点数，ST7789 显示 A/B 波形页，矩阵键盘调阈值和翻页。覆盖连续 DMA、双缓冲、事件 FIFO、门限统计、分页和局部刷新。

## 文档和代码边界

- 正式模块库的 `.c/.h` 保持冻结；每个工程只复制模块文件到自己的 `modules/`。
- SysConfig 以工程 `.syscfg` 为唯一硬件事实，生成文件只核对不手改。
- `main.c` 只组合 README API，并添加题目必需的少量数组、坐标映射、按键映射和状态机逻辑。
- 三个工程均已完成源码级整理；未在本机完成 CCS 全量构建和实板验证，状态均为 `BOARD NOT RUN`。
