# example02 步骤 01：模块选择与题目定义

## 一、预测题目

**扫频网络幅频/相频测试仪**：MCU 产生 500 Hz 至 8 kHz 的扫频激励，经过被测网络后
同时采集输入和输出，在 ST7789 上绘制幅频曲线或相频曲线；4×4 键盘选择曲线、重扫和
采样率档位。

## 二、比赛拆分顺序

1. 先用 DDS 波表和 DAC DMA 输出激励；
2. 用双路同步 ADC 采集网络输入/输出；
3. 对每个扫频点计算 Vpp 增益和上升过零相位；
4. 在 ST7789 上局部绘制幅频/相频点；
5. 用 4×4 键盘切换曲线、清空重扫和采样率。

## 三、复制的模块文件

从模块 README 的“可直接复制文件”复制到工程 `modules/`：

- `06_generator/dds`：`signal_dds.c/.h`、公共 `signal_status.h`；
- `06_generator/frequency_sweep`：`signal_frequency_sweep.c/.h`；
- `06_generator/dac_dma`：`signal_dac_dma_mspm0g3507.c/.h`；
- `02_acquisition/adc_dual_sync`：双路 ADC 平台文件及公共算法状态头；
- `03_measurement/phase`：`signal_phase.c/.h`；
- `01_bsp/matrix_keypad_4x4`：固定引脚键盘模块；
- `12_external_devices/display/st7789`：ST7789 核心和 MSPM0G3507 平台适配文件。

## 四、SysConfig 是否完全照 README

ADC、TIMG0、SPI1、固定键盘 GPIO 按 22_X 的 README 配置。新增 DAC12、TIMG6、Event 和
DMA 是因为本题需要真实激励：ADC 已占 `DMA_CH0/CH1`，DAC DMA 使用 `DMA_CH2`；这部分
参考 `PROFILE_03_DAC_GENERATOR` 和 `PROFILE_04_ADC_DAC`，不是擅自修改生成文件。原先
与 DAC 输出冲突的 `PA15 WAVE_SELECT` GPIO 已从本题 SysConfig 删除。

## 五、main 的自写边界

模块代码只负责波表、DMA、采集、相位 API 和屏幕图形 API；扫频点数组、Vpp、过零查找、
曲线像素映射、按键语义和主循环顺序均为 `main.c` 的少量组合逻辑。模块 `.c/.h` 未改。
