# example02 步骤 05：矩阵键盘与扫频控制

## 一、键盘模块代码

按 `matrix_keypad_4x4/README.md` 的固定引脚便利接口复制
`SignalMatrixKeypad4x4_ReadNewSymbol(&symbol)`。模块内部已经完成行列扫描、5 us 稳定
等待、3 次消抖和鬼键过滤；`main.c` 不再写 8 个 GPIO 回调。

## 二、按键定义

`App_ProcessKey()` 是本题自写映射：A 选择幅频曲线（`g_curve=0`），B 选择相频曲线
（`g_curve=1`），C 将 `g_point=0` 并清空界面开始重扫，D 在 50 kSPS/100 kSPS 间切换
并调用模块的 `SignalDualADC_SetSampleRate()`。字符以稳定按下事件为单位，不处理长按
重复。

## 三、主循环顺序

主循环每轮先读键，后运行一个扫频点，再在点号回到 0 时画一次静态界面。这样按键不会
被长时间 DAC/ADC 处理完全饿死；若实际 TFT 刷新耗时过长，应把扫频点处理改为状态机，
而不是在中断中刷屏。

## 四、与 README 的不同

键盘模块只输出字符，不知道“幅频/相频/采样率”的题意；这些映射全部由
`App_ProcessKey()` 自写。若要让用户输入任意频率，应复制矩阵键盘 README 第 20 节的
预输入缓冲，而不是直接把每个数字键立即写进 DDS。
