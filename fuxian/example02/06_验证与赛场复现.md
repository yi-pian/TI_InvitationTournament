# example02 步骤 06：验证与赛场复现

## 复现顺序

1. 先只生成 SysConfig，确认 ADC DMA 为 CH0/CH1、DAC DMA 为 CH2，SPI 与键盘 GPIO 无冲突；
2. 单独运行 DAC 全幅/固定频率测试，再接被测网络；
3. 接同一信号到 ADC 输入/输出，确认两路 Vpp 非零；
4. 按 A/B 检查两种曲线，按 C 观察点清空并重扫，按 D 检查采样率切换；
5. 逐频点用示波器核对激励频率，再核对屏幕点的位置和相位符号。
