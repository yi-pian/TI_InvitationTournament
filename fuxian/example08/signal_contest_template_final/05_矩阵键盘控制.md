# 步骤 5：矩阵键盘控制

按 `22_X` 的 SysTick 扫描方式：每 5 ms 调用 `SignalMatrixKeypad4x4_ReadNewSymbol(&symbol)`；只有模块确认“新稳定按下”才直接调用 `App_ProcessKey(symbol)`。ISR 只改 8-bit 状态和 revision，不画屏、不跑相位算法、不等待 DMA。

自写的 `App_ProcessKey` 逐项分发：

| 键 | 写入变量 | 效果 |
|---|---|---|
| `1`~`5` | `g_frequency_ratio` | 相位算法的 fY/fX |
| `A` / `D` | `g_page` | 图形页 / 诊断页 |
| `B` | `g_comp_threshold_mode=0`、DAC=128 | 1.65 V 过零测量 |
| `C` | `g_comp_threshold_mode=1`、DAC=155 | 约 2.00 V 门限实验 |

`B/C` 的 DAC 写入是 README 缺失后补在 `modules/README.md` 的唯一硬件桥接代码。DAC8 同时输入 OPA1 的片内基准缓冲；相位实验必须按 `B` 恢复到 1.65 V 门限。
