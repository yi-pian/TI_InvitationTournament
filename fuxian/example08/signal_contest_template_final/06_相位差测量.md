# 步骤 6：相位差测量

采样完成后复制相位模块 README 调用：

```c
phase_status = SignalDualADCPhase_Process(g_raw_a, g_raw_b,
    SIGNAL_SAMPLE_COUNT, SIGNAL_SAMPLE_RATE_HZ, &g_phase_config, &phase_result);
```

本题只自写两行：把键盘比例赋给 `g_phase_config.frequency_ratio`，在结果有效时保存 `phase_degrees`，否则显示 `--`。模块负责迟滞过零、幅度判定和角度归一化。

验收：B 模式、PA26 输入 1 kHz/1.65 V 偏置正弦；OPA0 与 GPAMP 都为单位增益缓冲，屏幕相位应稳定在 0° 附近。幅度太小或不以 1.65 V 为中心时，结果无效是预期保护行为。
