# 步骤 4：ST7789 显示李萨如图

先复制显示 README 的初始化/清屏代码：

```c
g_tft_status = SignalTFTST7789_MSPM0_Init(&g_tft, TFT_ST7789_ROTATION_270, 0U, 0U);
g_tft_status = TFT_ST7789_FillScreen(&g_tft, TFT_ST7789_BLACK);
```

`App_FindBounds`、`App_MapX/Y`、`App_DrawSafeLine`、`App_DrawLissajous` 是本题少量自写组合逻辑：先找出一帧 512 个 12-bit ADC 码的最小/最大值，再自动映射到绘图区；跨度低于 64 码时固定画在图心，不把噪声放大成横线/竖线。自动量程的轨迹四周固定留 4 像素，不贴蓝色边框。显示时使用完整 512 个连续采样点，而非只显示帧开头 128 点；每个点调用 README 的 `TFT_ST7789_DrawPixel`，每一对相邻点均经 `App_DrawSafeLine` 验证端点在绘图区后调用 README 的 `TFT_ST7789_DrawLine` 连成实线；只拒绝绘图区外的异常端点，不再按长度丢弃正常线段。驱动模块已修复 Bresenham 的 `err` 快照缺陷，`DrawLine` 会正确到达终点。相位算法使用同一完整帧。边框和坐标轴仍用 `FillRect`，自动量程只影响显示，传给相位算法的仍是原始 ADC 码。横轴是 OPA0 缓冲输出，纵轴是 GPAMP 缓冲输出。

按 `22_X` 改为局部刷新：标题、标签、蓝色边框和坐标轴只在上电或 A/D 换页时画一次；每次采样只清除边框内的波形区，重画黄色轨迹，并擦除/重画相位、计数和 `A RAW`/`B RAW` 数字矩形。`A RAW` 和 `B RAW` 分别是 ADC0(OPA0/CH13) 与 ADC1(GPAMP/CH14) 本帧最小码-最大码，是接线诊断数据。

PA26 输入同频正弦时，应接近一条正斜率直线；需测试不同频率比例时可用 `1`~`5` 选择对应李萨如比例。
