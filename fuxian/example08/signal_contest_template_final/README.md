# example08：多模式片上模拟前端双通道信号分析仪

这是按比赛现场顺序完成的 MSPM0G3507 工程。它不是“软件模拟”运放：GPAMP、OPA0 单位增益缓冲、OPA1 的 COMP.DAC8 基准缓冲、COMP0、ADC0/ADC1、DMA、TIMG0、SPI LCD、矩阵键盘都已在 SysConfig 中配置并被 `main.c` 使用。

## 做什么

PA26 的带偏置信号并联进入两个高阻片内前端：GPAMP 的 ADC Buffer 输出由 ADC1 内部 CH14 采样；OPA0 的单位增益 Buffer 输出由 ADC0 内部 CH13 采样。OPA1 同时将 COMP0.DAC8 作为片内基准缓冲，供 DAC/比较器实验页观察。两个 ADC 用同一个 TIMG0 事件与 DMA 同步采集，屏幕显示李萨如图和相位差。COMP0 同时监视 PA26，在硬件中断中累计上升/下降边沿。

只需给 PA26 输入以 1.65 V 为中心的正弦波；PA24 不参与本版本采样，不能再短接。LP-MSPM0G3507 原厂手册规定 J18 默认把 PA26 接到板载光敏二极管电路，作外部信号输入时必须拔掉 J18；拔掉后先接好信号源和共地，不能让 PA26 悬空。GPAMP 与 OPA0 都是同相缓冲，屏幕相位应接近 0°；这是最直接的整机验收。

## 七个比赛步骤

1. `01_模块选择与复制.md`：先选模块、再原样复制到 `modules/`。
2. `02_板载OPA与SysConfig配置.md`：配置 GPAMP、OPA0/OPA1 和内部 ADC 通道。
3. `03_双路ADC同步采集.md`：配置 Timer/Event/DMA，并确认两路同步。
4. `04_ST7789李萨如图显示.md`：显示李萨如轨迹和状态栏。
5. `05_矩阵键盘控制.md`：用键盘改比例、页面和比较器模式。
6. `06_相位差测量.md`：由纯算法模块输出相位。
7. `07_main逐行解释与验证.md`、`08_比较器与完整测试.md`：核对复制代码、自写逻辑、接线和测试。

## 接线与按键速查

| 项目 | 接法/动作 |
|---|---|
| 被测正弦 | 输出接 `PA26`，并与板 `GND` 共地；推荐 1.65 V DC 偏置、幅度不大于 0.2 Vpeak |
| PA24 | 本版本不使用；保持悬空，不能再接 `PA26 -> PA24` |
| 供电约束 | 输入不得低于 GND 或高于 VDDA；先从 1 kHz、1.65 V±0.1 V 开始 |
| `1`~`5` | 设置相位算法的 `fY/fX` |
| `A` / `D` | 李萨如页 / 模拟前端诊断页 |
| `B` | COMP0 1.65 V 过零模式；做相位实验前使用 |
| `C` | COMP0 约 2.00 V 门限模式；观察按同门限 ADC 帧统计的边沿变化 |

`PA26` 被 GPAMP 和 COMP0 同时作为高阻模拟输入。SysConfig 中对此显式使用官方示例同类的共享资源声明；这不是两个输出短接。
