# 步骤 1：模块选择与复制

像 `22_X` 一样，先把题拆成独立小题，再复制模块，最后写组合层。

| 小题 | 选用模块 | 为什么选 |
|---|---|---|
| GPAMP 缓冲 | `signal_gpamp`、`signal_gpamp_buffer` | 使用板上 GPAMP 和 ADC-assisted chopping |
| OPA0 缓冲 | `signal_opa` | 采用 TI Buffer Quick Profile，将 PA26 可靠送入 ADC0 CH13 |
| OPA1 DAC 缓冲 | `signal_opa` | 缓冲 COMP.DAC8，覆盖片内基准路径且不与 SPI1 的 PA16 冲突 |
| 反相/程控 PGA | `signal_opa_inverting`、`signal_opa_noninverting_pga` | 已复制并保留为比赛模块；旧反相链实测饱和，当前版本不启用 |
| 门限/过零 | `signal_comparator*` | COMP0 硬件 DAC 门限；实板 IRQ 不稳定时以同门限 ADC 帧统计边沿 |
| 同步采样 | `signal_dual_adc_mspm0g3507` | ADC0/ADC1 + DMA + TIMG0 |
| 显示/交互/算法 | ST7789、键盘、相位模块 | 形成可展示闭环 |

复制顺序：公共状态头 → OPA/GPAMP/COMP → ADC DMA → LCD/键盘 → 相位。具体文件和来源见 `COPIED_MODULES.md`。复制后 Refresh CCS，确认每个 `.c` 均参与 Build；本题原规则是不编辑模块源码，唯一例外是实测并遍历验证的 ST7789 `DrawLine` 无限循环缺陷，已按授权修复并同步集成库。

本题自己写的仅是 `main.c` 的 App 映射/显示/按键调度和 COMP DAC 切换；所有接口计算、DMA、显示、键盘、相位处理均为 README 代码调用。
