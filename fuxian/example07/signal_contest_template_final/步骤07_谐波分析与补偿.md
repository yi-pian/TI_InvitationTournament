# 步骤07：1、2、3 次谐波分析与补偿

按键 3 依次输出 1 kHz 基波、2 kHz 二次谐波和 3 kHz 三次谐波，每次都走双 ADC + Lock-In，得到三组幅度比和相位差。README 没有“多谐波合成”接口，因此只在 `main.c` 增加一个固定 1024 点循环：以目标权重（1、1/2、1/3）除以对应实测增益，并将相位取负后叠加三个正弦。目标的 0° 相位基准与 `SignalSine_Generate` 一致，不能误用余弦；再按三项绝对值之和归一化，调用 `SignalDACWaveTable_NormalizedToRaw` 写入 DAC 表。

这段循环是本题允许的少量应用逻辑；没有复制或修改模块内部实现。合成表作为 DDS 查表源，以 1 kHz 基波播放，最后由 DAC DMA 连续输出补偿后的周期波形，屏幕第三页显示完成状态。进入本步骤时会先停止可能正在输出的 1 kHz 单音补偿，以便重新配置 DAC Timer。
