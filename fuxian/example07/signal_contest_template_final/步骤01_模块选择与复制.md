# 步骤01：模块选择与原样复制

比赛先不写 `main.c`。按题目数据流选择：双 ADC 负责网络输入/输出，DAC DMA+波表+Sine+DDS 负责按频点产生测试信号，Frequency Sweep 负责 0.5 kHz～10 kHz 点列，Lock-In 负责幅相，Frequency Response Correction 负责逆响应，ST7789/8×16 负责显示，4×4 Keypad 负责操作。

复制到 `modules/` 的 `.c/.h/.inc` 见 [COPIED_MODULES.md](COPIED_MODULES.md)。文件均来自仓库已有模块目录；未改动源文件内容。`signal_status.h` 和 `signal_algorithm_status.h` 是公共依赖，也一并复制。

这一阶段只做 CCS Refresh 和 source entry 检查，不把 `README_*_MINIMAL.c` 当作工程源文件编译。
