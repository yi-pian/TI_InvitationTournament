# 步骤06：1 kHz 自动预补偿

按键 2 先停止当前 DAC 连续输出并确保扫频完成，再把每个测量点写成 `gain_correction=1/H_gain`、`phase_correction=-H_phase`，调用 README 的 `SignalFrequencyResponseCorrection_Process` 做对数插值。将返回的增益限制在 0.25～4，调用 `SignalSine_Generate` 生成查表源，再用 DDS 生成预补偿 1 kHz 波形，重新采集并计算误差。复测完成后不停止 DAC DMA，PA15 持续输出该预补偿 1 kHz 波形；再次按 `1`、`2` 或 `3` 时，程序才停止旧波形并切换任务。

屏幕第二页显示幅值误差百分比和相位误差。是否达到幅值 ≤3%、相位 ≤5° 必须连接真实未知网络上板测量；源码和离线编译不能替代实测。
