# example07 比赛现场总步骤

1. 选模块并复制 `.c/.h/.inc`，登记到 `COPIED_MODULES.md`。
2. 按各 README 打开 SysConfig：先 ADC/DMA/Timer，再 DAC/FIFO/DMA/Timer/Event，再 SPI、GPIO、键盘；Generate 后核对宏。
3. 只复制 README 的初始化和 API 调用到 `main.c`，每完成一个大步骤就 Build。
4. 先完成双 ADC 采集，再完成 ST7789/8×16 显示和键盘；确认 A/D、1、2、3 按键。
5. 按 1 扫 0.5 kHz～10 kHz，记录输入/输出幅值和相位，显示幅频/相频。
6. 按 2 生成 1 kHz 逆响应预补偿，重新测量并检查 ≤3%、≤5° 指标。
7. 按 3 测 1/2/3 次谐波，按逆增益和负相位合成补偿波形。
8. 对照《步骤08_main代码逐段解释》逐段核对复制代码和自写逻辑，再做 Clean/Build 与上板验证。
9. 若屏幕显示非本题文字或按键无可见反应，按《步骤09_上板排错与下载》先确认下载的工程和 `.out`。

本题的扫频上下限、1 kHz 补偿目标和 1/2/3 次谐波基波参数均放在 `main.c` 的题目参数区；`signal_config.h` 保持母版默认值。`main.c` 已按 example05 风格补充硬件数据链、比赛大步骤、缓冲区用途、每个模块 API 的输入输出、异常返回和自写逻辑说明；详细行号解释见《步骤08_main代码逐段解释》。

复制代码：各模块 README 的 include、初始化、Start/Stop、Generate、Process、ST7789 绘图和键盘扫描。自写代码：数组、电压换算、输入输出比值、相位包络、逆表填充、按键状态机、三谐波有限循环和页面布局。上板发现 DMA 完成中断遗漏后，已按 22_X 修复 `signal_dual_adc_mspm0g3507.c`；除此以外模块 `.c/.h` 未修改。当前完成了编译级验证，真实误差指标仍需接未知网络后用示波器或采样结果确认。
