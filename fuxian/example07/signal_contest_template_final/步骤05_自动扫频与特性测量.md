# 步骤05：自动扫频、幅频和相频

按键 1 后复制 `SignalFrequencySweep_Generate` 生成 16 个对数频点。每一点先将 DAC 更新率设为“当前频率 × 100”，再用 `SignalSine_Generate` 生成 1024 点查表源，按补充 README 的 `SignalDDS_Init`、`SignalDDS_Fill` 填充 100 点 DAC 周期缓冲，最后用 `SignalDACDMA_MSPM0_Start` 循环输出；采集完成后分别对输入和输出调用 `SignalLockIn_Process`。`SignalDACDMA_MSPM0_GetConfiguredRate()/100` 作为实际频率写回扫频表和 Lock-In 参考，避免 Timer 整数分频误差。10 kHz 时更新率为 1 MSPS，正好是本片内 DAC 的上限。

本题新增逻辑为 `gain=output_amplitude/input_amplitude`、`phase=output_phase-input_phase`，并把相位包到 ±180°。屏幕第一页以表格显示 16 个扫频点中的 1、6、11、16 点，列出频率、增益和相位，作为幅频/相频特性的现场快速查看结果；完整 16 点仍保存在 RAM 中供 1 kHz 插值。
