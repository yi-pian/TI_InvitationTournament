# moni02：内置 DAC + DDS 可调波形发生器

本工程使用 MSPM0G3507 内置 DAC、定时器和 DMA 输出正弦波、方波、锯齿波；使用 4×4 矩阵键盘修改参数，并在 ST7789 TFT 上显示设置值和实际输出频率。

## 按键

| 按键 | 功能 |
|---|---|
| `A` | 正弦波 → 方波 → 锯齿波循环切换 |
| `B` | 选择待修改参数；正弦波只有频率/Vpp，方波和锯齿波增加形状参数 |
| `0`～`9` | 直接输入当前参数的新数值 |
| `*` | 输入小数点 |
| `D` | 输入过程中删除最后一位 |
| `C` | 输入过程中取消；空闲时恢复默认值 |
| `#` | 确认输入并更新 DAC |

黄色数值是当前编辑项。输出范围为 100 Hz～10 kHz、0.2～3.0 Vpp；方波占空比为 5%～95%，锯齿波对称度为 5%～100%。例如输入 5000 Hz：`5000#`；输入 1.5 Vpp：`1*5#`；输入 25%：`25#`。

## 首次在 CCS 构建

复制文件后，先右键工程选择 **Refresh**，确认 `modules` 中全部 `.c` 文件没有 **Exclude from Build**，然后执行 **Project → Clean** 和 **Build Project**。旧的 `Debug/makefile` 不会自动认识刚复制的源文件，必须让 CCS 刷新并重新生成。
