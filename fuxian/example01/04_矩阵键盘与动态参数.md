# example01-4 矩阵键盘与动态参数

## 复制内容

直接复制键盘 README 的固定引脚便利接口调用：`SignalMatrixKeypad4x4_ReadNewSymbol(&symbol)`。它内部完成 PB16/PB0/PB7/PB17 行扫描、PB18/PB13/PB20/PB4 列读取、3 次消抖和鬼键过滤，main 不重复写扫描代码。应用使用 `SysTick_Config(CPUCLK_FREQ / 1000U)` 启动 1 ms 节拍，在 `SysTick_Handler()` 中每 5 ms 扫描一次；识别出的字符进入 8 字节队列，不在中断里改 ADC Timer。

## 自写代码逐行解释

```c
void SysTick_Handler(void)
{
    static uint8_t milliseconds;
    char symbol;
    if (++milliseconds < 5U) return;
    milliseconds = 0U;
    if (SignalMatrixKeypad4x4_ReadNewSymbol(&symbol) == SIGNAL_RESULT_OK) {
        App_QueueKey(symbol); /* 中断只入队，不改 ADC Timer。 */
    }
}

/* 主循环在上一帧采样完成后取出队列并执行参数修改。 */
if ((symbol >= '1') && (symbol <= '5')) g_page = symbol - '1';
else if (symbol == 'A') g_threshold -= 64U;
else if (symbol == 'B') g_threshold += 64U;
else if (symbol == 'D') {
    g_sample_rate = (g_sample_rate == 100000U) ? 50000U : 100000U;
    SignalDualADC_SetSampleRate(g_sample_rate);
}
```

真实代码还用上下限保护，防止门限低于 64 或高于 4031；采样率只在上一帧完成后的主循环调用，不放进 ISR。状态区使用 ST7789 新字库的 8×16 ASCII 字体，顶部和右侧均显示文字标签，不再只显示无标签数字。`g_page` 只是预留页面状态，目前没有五个独立页面的绘图逻辑；`1`～`5` 不会改变当前波形画面。
