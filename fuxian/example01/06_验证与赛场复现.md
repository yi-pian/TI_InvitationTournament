# example01-6 验证与赛场复现

1. Import CCS 工程，确认 `modules/` 中所有 `.c` 没有 Exclude from Build。
2. 打开 `.syscfg`，按前四步核对 ADC0/ADC1、DMA、TIMG0、SPI1 和键盘 GPIO，Generate 后只读检查宏。
3. Clean/Build；当前工程已用 TI ArmClang `-Wall -Werror` 编译链接通过，产物位于 `signal_contest_template_final/Debug/signal_contest_template_final.out`。
4. 上板时先只显示静态 ST7789 边框，再接入 X/Y，检查两路数组是否同时变化。
5. 用示波器给 X/Y 同频信号，验证两次 X 上升沿周期；改变 A/B/D，确认门限和 Fs 只在下一帧生效。键盘由 SysTick 每 5 ms 扫描，绿色状态框第三行按键计数应递增；`1`～`5` 当前只更新预留页面状态。

结论：步骤遵循模块 README，差异和自写代码已在前五份文档列明；用户已实机确认 TFT 波形和键盘响应，ADC 精度、相位测量和完整题目指标仍需继续验证，当前状态 `BOARD PARTIALLY VERIFIED`。
