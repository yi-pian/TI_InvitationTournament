# example01-1 模块选择与题目定义

## 题目

预测题：双通道可调信号分析仪。输入 X/Y 为同步模拟信号，要求显示时域波形、改变采样率和门限，并计算两路同方向上升过零的相位差。

## 模块选择

选择 `adc_dual_sync`、`phase`、`matrix_keypad_4x4`、`st7789`。双 ADC 保证两个数组的第 i 点来自同一 Timer 触发；phase 只做数学换算；键盘模块封装扫描、消抖和鬼键过滤；ST7789 模块封装 SPI 命令。

## 复制清单

从各模块 README 的“复制哪些文件”复制 `signal_dual_adc_mspm0g3507.c/.h`、`signal_phase.c/.h`、`signal_matrix_keypad_4x4.c/.h`、`signal_tft_st7789.c/.h`、`signal_tft_st7789_mspm0g3507.c/.h`、`signal_tft_st7789_font.c/.h`、`signal_tft_st7789_font_data.inc` 和公共状态/算法头到 `modules/`。ST7789 字库提供 6×12、8×16、12×24、16×32 ASCII 字模，本题统一使用 8×16；适配层沿用新模块的 SPI 实现。

## main 自写代码

`main.c` 中的 `APP_PLOT_*` 是屏幕布局；`g_raw_x/g_raw_y` 是应用数组；`App_MapSampleX/App_MapY` 把采样序号和 12 位 ADC 码转换为像素；绘图、过零插值、键盘动作、SysTick 按键队列和主循环是应用组合代码。除这些组合逻辑外，初始化/调用顺序来自 README。
