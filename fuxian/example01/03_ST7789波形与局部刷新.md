# example01-3 ST7789 波形与局部刷新

## SysConfig 与 README 对照

按 `st7789/README.md` 添加 SPI1 和控制 GPIO。SPI1 使用 PB9 SCLK、PB8 MOSI、PB6 CS；DC/PWM 背光使用 PB15/PB12。当前初始化调用为 `SignalTFTST7789_MSPM0_Init(...TFT_ST7789_ROTATION_270...)`。本题没有复制 ILI9341；ST7789 的 MSPM0 SPI 适配层按 `22_X` 方式清理 RX FIFO，减少逐字节阻塞等待。

## 自写坐标代码逐行解释

```c
return APP_PLOT_X + (index * (APP_PLOT_W - 1)) /
    (SIGNAL_SAMPLE_COUNT - 1); /* 采样序号映射到绘图区横轴。 */
return APP_PLOT_Y + APP_PLOT_H - 1 - (code * (APP_PLOT_H - 1)) / 4095; /* Y 翻转坐标。 */
```

`4095` 是 12 位 ADC 最大码；横坐标使用采样序号而不是 ADC 码；各处减一保证不越过边框；Y 减法是因为屏幕向下为正。

`App_DrawStaticUi()` 只调用一次，画黑底、蓝色边框、坐标轴、绿色状态框和 8×16 字体的固定标签；`App_DrawTrace()` 先用 `FillRect` 清除绘图区内部，再重画中心坐标轴，并把 1024 点降采样为 220 个显示点绘制两路时域波形。因此蓝框、坐标轴和固定标签不会消失。`App_DrawStatus()` 使用新字库的 `TFT_ST7789_DrawString()`、`TFT_ST7789_DrawInt32()`，只局部刷新采样率、门限、按键计数、页码和相位值。顶部显示 `DUAL ADC`、`SYNC`、`Fs`、`TH`、`KEY`、`TIME WAVE`、`X:Y`、`PH`、`PG`；右侧显示 `CH1 X`、`CH2 Y`、`RATE`、`THRESH`、`KEY CNT` 和 `PAGE`。
